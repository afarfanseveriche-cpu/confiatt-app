# Confiatt · app instalable

Cáscara instalable (PWA) que abre el Sistema de Gestión de Confiatt a pantalla completa en el teléfono, con ícono propio, pantalla de bienvenida, accesos rápidos y aviso sin conexión.

- `sg/` — Sistema de Gestión (pruebas). La dirección del sistema está en `sg/index.html` (`URL_SISTEMA`).
- Publicado con GitHub Pages desde la rama `main`.
